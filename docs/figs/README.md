# docs/figs — 그림의 출처와 라이선스

이 폴더에는 **두 종류**가 섞여 있다. 섞어서 다루면 라이선스 사고가 난다.

| 종류 | 캡션 밑 `출처:` 줄 | 고치는 법 |
|---|---|---|
| **외부 저작물** | 🔴 **저작자·저널·연도·라이선스를 전부** 적는다 | 고칠 수 없다 — 원본 그대로 쓴다 |
| **우리가 그린 것** | 저자 작성 | 🔴 **생성 스크립트**를 고치고 다시 돌린다 |

🔴 **새 그림을 넣을 때는 아래에 절을 먼저 추가한다.** 출처 없이 들어간 외부 그림은
발표 자료로 나갈 때 라이선스 위반이 된다.

## arch-pipeline.svg · .png · .pdf — 🖊️ **우리가 그린 것**

시스템 아키텍처. 화물 입력 → 설계(LLM) → 채점 → 심사 → 순위의 5개 계층.

| 항목 | 내용 |
|---|---|
| **출처** | 저자 작성 (외부 저작물 아님 · 라이선스 표시 불필요) |
| **생성** | `/usr/bin/python3 scripts/make_fig_architecture.py` |
| **규격** | SVG 1000×1066 · PNG 1800×1919(15cm 폭에서 **305 dpi**) · PDF 벡터 |
| **구조 기준** | 2026-11-19 |

🔴 **SVG 를 손으로 편집하지 말 것.** 스크립트가 출처다. 손으로 고치면 다음에
스크립트를 돌릴 때 조용히 덮어써진다.

🔴 **흑백 인쇄 설계**다. 색상(hue)에 의존하지 않고 **명도 + 선 종류**로만 가른다 —
LLM 상자는 흰 바탕 + 굵은 테두리, 결정론 상자는 회색 바탕, 보고치는 파선 테두리.
색을 넣으면 이 구분이 깨진다.

### 그림이 주장하는 것 — 본문과 어긋나면 안 되는 4가지
1. **생성은 ② 한 곳**에서만 LLM 이 한다. Critic(④)도 LLM 이지만 **판정**만 한다.
2. **deepB3P 는 파선**이다 — 엔진으로 돌지만 **순위에 들어가지 않는다**.
3. 게이트 7개는 Critic 의 판정을 **단방향으로** 덮는다(화살표가 한 쪽).
4. **복구는 게이트의 짝**이다 — `재설계 기회 소진` 화살표가 복구로 들어간다.
5. ⑤ 는 **사전식이 아니다**. `dominates()` 가 근거 그룹을 위험 4축과 **같이** 넣어
   한 번에 비교하고(5축), 최상위 그룹은 전선을 **만든 뒤에** 거른다(`front_top`).
   사전식이면 전선 23 과 최상위 그룹 전선 5 가 갈릴 수 없다 — 그 18개가 증거다.
   사전식 순서(`rank_key`)는 동급 중 하나를 제시할 때만 쓴다(수치원장 Ⅳ).

⚠️ 구조가 바뀌면 이 5가지부터 확인한다. 특히 **엔진 6종**과 **게이트 7개**는
숫자가 캡션·본문·그림 세 곳에 있다.

**그림 내용과 이 프로젝트의 관계** — (c) 칸이 **수용체매개(RMT) · 운반체매개 ·

미세혈관에서 더 높게 발현")이 §50 의 수용체 발현 대조가 잰 것이다.

🔴 이 그림을 발표에 띄울 때는 **우리 도구가 닿는 칸이 어디까지인지** 한 문장을
같이 적는다. `rmt_sim` 은 참조 셔틀과의 **BLOSUM62 서열 유사도**이고 수용체 결합을
측정한 적이 없다.
