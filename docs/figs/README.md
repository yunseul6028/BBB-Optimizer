**그림 내용과 이 프로젝트의 관계** — (c) 칸이 **수용체매개(RMT) · 운반체매개 ·
흡착매개(AMT)** 를 **다른 칸**으로 그린다. 우리 `off_target` 은 전하 기반이라
**AMT 칸의 질문**인데 Angiopep-2·T7·THR 같은 **RMT 셔틀에게** 묻고 있다(§50).
(d) 칸은 뇌 표적 수용체의 요건 3개를 적어 놓았고, 그 중 ①("다른 조직보다 뇌
미세혈관에서 더 높게 발현")이 §50 의 수용체 발현 대조가 잰 것이다.
