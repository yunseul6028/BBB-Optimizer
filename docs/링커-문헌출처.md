셔틀의 `core/evidence.py` 에 대응하는 **링커 쪽 단일 출처**다. 코드의
`core/config.py` → `LINKER_LIBRARY[*]["ref"]` 가 이 문서의 키를 가리킨다.
🚫 서지를 코드에 복제하지 말 것(드리프트). 🚫 등급을 코드로 계산하지 말 것 —

측정일 2026-11-12. 확인 경로는 NCBI E-utilities 초록 전문과 PMC 전문(XML)이다.

## 3. 🔴 `(GGGGS)n` 에는 1차 출처가 없다 — 인용 함정

이 분야 표준 리뷰(**Chen2013**)의 유연 링커 절을 전문에서 확인했다. 원문은

> "An example of the most widely used flexible linker has the sequence of (Gly-Gly-Gly-Gly-Ser)n."

이고, **이 서열에 붙은 참조 번호가 없다.** 리뷰가 거기서 인용하는 **Argos1990** 은
Gly·Ser 풍부 펜타펩타이드 링커라는 **원리**의 출처이고(초록: PDB 51개 링커 추출 →
펜타펩타이드 후보 제안), **`GGGGS` 라는 서열을 명명하지 않는다.**

그리고 리뷰 Table 3 은 scFv 의 `(GGGGS)3` 를 **Huston1988** 에 귀속시키는데,
Huston1988 의 초록·PMC 본문에는 **"connected by a 15-amino acid linker"** 뿐이고
**서열이 적혀 있지 않다**(PMC281868 확인).

➡️ **`(GGGGS)n` 을 Huston1988 로 인용하면 2차 인용이다.** 서열이 실제로 적힌
가장 가까운 1차 문헌은 **Lu2008** 이다(우리 라이브러리의 n=1·2·3 이 그 논문의 격자와 일치).
🚫 Huston1988 을 서열 출처로 쓰지 말 것. 맥락(scFv 고전 길이 15aa)으로만 쓴다.

## 4. 🔴 이 문서가 **주지 않는** 것

- **전달 근거 등급이 없다.** 셔틀은 `core/evidence.py` 의 5불리언 루브릭으로 등급(B/C/D)이
  나오지만, 링커에는 "BBB 를 통과시킨다"는 주장 자체가 없다. 위 출처들이 지지하는 것은
  **융합 단백질에서의 도메인 분리·발현량·활성**이고 **뇌 전달이 아니다**.
  🚫 링커 표에 셔틀 표와 같은 꼴로 "근거등급" 열을 달지 말 것 — "링커도 문헌 근거로 골랐다"로 읽힌다.
- **이 13종을 고른 근거가 아니다.** 출처는 서열이 존재한다는 것만 말한다. 왜 이 조합인지는
  측정이 답하는데, 그 측정은 **음성**이다 — M8 §17 에서 라이브러리 링커가 같은 길이 무작위에게
  **0/108**(108셀 전부 무작위 승)로 졌다. [[수치원장]] Ⅴ 5절.
- **길이-기능 관계가 아니다.** "길면 독성 감소"는 거짓으로 측정됐다(56계열 중 단조 0개, §44-2).
  방향을 정하는 것은 길이가 아니라 **조성**이다.
- **17aa 상한의 근거가 아니다.** 상한은 `max(len(라이브러리))` 로 **유도된 값**이고 측정이 아니다.
  🚫 "독성 희석 우회를 막는다"는 금지 문구다(막는 우회 0/14, §44-3·4). 남은 근거는
  **"라이브러리와 같은 길이 운동장 = 대응 널의 범위 선택"** 하나뿐이다.

## 6. 남은 공백

- [ ] `GGS`(3aa) · `GGGGGS`(6aa) 의 출처 — **못 찾음.** 선택지 ⑴ 출처를 더 찾는다
      ⑵ 우리 구성물로 재분류한다 ⑶ 라이브러리에서 뺀다(조합 수 156 → 132 로 바뀌므로
      서론·§10·§16 을 전부 고쳐야 한다). **아직 결정 전.**
- [ ] `EAAAK` · `(EAAAK)2` 의 **측면 알라닌 없음** — Arai 의 구성 형태는 `A(EAAAK)nA` 이고
      측면 A 가 헬릭스 말단을 닫는다. 우리 두 종은 그게 없어 **Arai 구성물이 아니다**.
      Lu2008 의 `(EAAAK)n` 형태와는 일치한다. 논문에 쓸 때 두 계보를 섞지 말 것.
- [ ] 라이브러리 13종이 **왜 이 13종인지**는 어떤 문헌도 지지하지 않는다 → 7절 한계 재료.
